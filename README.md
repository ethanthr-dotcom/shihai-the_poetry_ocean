## 📖 项目故事

在信息快速流动的今天，我们每天接触大量文字，却越来越少停下来阅读那些跨越千年的诗句。

中国古典诗词曾记录过无数人的情感：
有杜甫忧国忧民的沉吟，有李白仗剑远游的豪情，有苏轼面对人生风雨时的旷达。
然而，许多珍贵的诗词资源仍停留在数据库或传统文本中，与现代读者之间存在距离。

因此，我创建了「诗海」——希望通过现代互联网技术，让这些古老的文字拥有新的呈现方式。
诗海不仅是一个诗词展示网站，更是一场关于传统文化与数字时代相遇的探索。

> 当代码遇见诗歌，当数据承载文明，
> 那些曾经被吟诵千年的文字，依然可以在今天的世界里继续闪耀。

## 🛠️ 技术栈

### 架构概览

```
网页端    浏览器 ──► 单文件 index.html ──► data/*.json（本地相对路径 / jsDelivr CDN）
小程序端  页面 ──► wx.cloud.callFunction ──► poemData / poemData2（数据 gzip 打包在函数内）
```

两端共享同一套 `data/` 数据，小程序通过云函数中转。数据层逻辑在两端是同构的。

| 部分 | 技术 |
|---|---|
| 网页端 | 单文件 `index.html`（原生 HTML/CSS/JS，零框架零构建） |
| 主题系统 | CSS 自定义属性（变量）动态注入，16 配色 × 3 排版即时切换 |
| 分享图 | Canvas 2D 逐字手绘排版，横/竖版双布局 |
| 字体 | 系统字体栈（Songti SC / STSong / SimSun / PingFang SC / serif），免网络加载，秒开 |
| 数据分发 | jsDelivr CDN（网页）/ 微信云开发云函数（小程序，gzip 打包） |
| 小程序 | 微信原生小程序 + 多端应用，Web 端功能完整移植 |
| 数据管线 | Python：繁简转换（zhconv）、乱码清理、切片、两级索引 |

## 🔧 本地部署指南（手把手教学）

> 别担心，跟着步骤一步一步来，一定能跑起来！

### 方式一：网页版（最简单，30 秒搞定）

> 适合：只想在电脑上看看效果的人

**第 1 步：下载项目**

打开终端（Mac 按 `Command + 空格`，输入 `Terminal` 回车），复制粘贴下面两行命令：

```bash
git clone https://github.com/ethanthr-dotcom/shihai-the_poetry_ocean.git
cd shihai-the_poetry_ocean
```

> 如果你没有安装 git，也可以去 GitHub 页面点绿色的 `Code` 按钮 → `Download ZIP`，解压后用终端 `cd` 进去。

**第 2 步：启动本地服务器**

在终端里输入：

```bash
python3 -m http.server 8080
```

> 看到 `Serving HTTP on ...` 就说明成功了！
> 如果提示找不到 `python3`，试试用 `python` 代替。

**第 3 步：打开浏览器**

在浏览器地址栏输入：

```
http://localhost:8080/
```

就能看到诗海了！🎉

> **小知识**：网站会自动识别你在本地运行，直接从 `data/` 文件夹读取数据，不走网络 CDN，所以速度特别快。当你部署到线上时，它会自动切换为 CDN 数据源，完全不用改代码。

---

### 方式二：微信小程序（需要云开发）

> 适合：想在手机上、微信里使用的人

**准备工作**（需要提前准备好）：

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册一个小程序账号，拿到自己的 **AppID**
3. 在微信开发者工具中开通 **云开发** 环境

**第 1 步：导入项目**

打开微信开发者工具，点击「导入项目」：

- 项目目录：选择本仓库根目录
- AppID：填你自己的

> 仓库里有一个 `project.config.example.json` 模板文件。把它复制一份，改名为 `project.config.json`，然后把里面的 `appid` 换成你自己的。
> （这个文件已经被 `.gitignore` 忽略了，不会上传到 GitHub，放心。）

**第 2 步：填写云开发环境 ID**

打开 `miniprogram/utils/config.js`，找到这一行：

```js
const CLOUDBASE_ENV = "cloud1-d2gtpvp0j78a22e70";
```

把引号里的内容换成你自己的云开发环境 ID。
（在微信开发者工具的「云开发」控制台 → 设置 → 环境 里可以找到。）

**第 3 步：在云开发控制台添加权限**

云开发控制台 → 设置 → 环境访问权限 → 添加你的 AppID。

**第 4 步：上传并部署云函数**

在开发者工具左侧文件树中：

1. 右键 `cloudfunctions/poemData` 文件夹 → 点击「上传并部署：所有文件」
2. 等待上传完成（约 17MB，1-2 分钟）
3. 右键 `cloudfunctions/poemData2` 文件夹 → 点击「上传并部署：所有文件」
4. 等待上传完成（约 24MB，1-2 分钟）

> **为什么有两个云函数？**
> 因为微信云函数单个部署包不能超过 50MB，而我们的数据 gzip 后约 40MB，所以拆成了两个：
> - `poemData`：存放索引 + 分块 001-140
> - `poemData2`：存放分块 141-345
>
> 小程序会根据分块号自动选择走哪个函数（`CLOUDBASE_SPLIT = 140`），你不需要操心。

**第 5 步：编译运行**

点击开发者工具顶部的「编译」按钮，就能在模拟器里看到诗海了！🎉

> 启动时会自动预热两个云函数，之后随机抽诗就走云函数取数，非常快。

### 方式四：重新生成数据（高级）

> 适合：想从原始语料重新生成数据分块的人

**第 1 步：安装依赖**

```bash
pip3 install zhconv
```

> `zhconv` 是一个繁体转简体的 Python 库，只需安装一次。

**第 2 步：运行转换脚本**

```bash
python3 tools/convert_chinese_poetry.py
```

这个脚本会做以下事情：
1. 读取 `sources/chinese-poetry` 目录下的原始语料
2. 繁体统一转为简体
3. 清理 PUA 码位与乱码字符（替换为 `□`）
4. 推断体裁（五七言绝句/律诗/古风等）
5. 去重（按作者+标题+正文前 20 字）
6. 切分为 345 个分块（每块 1000 首）
7. 生成精简索引和筛选索引

**第 3 步（可选）：重建搜索索引**

```bash
python3 tools/rebuild_search_index.py
```

这个脚本会移除高频字符（出现在 >50% 分块中的字符），将搜索索引体积减小约 59%。

### 数据来源

诗词数据来源于开源项目 [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT License），涵盖：

- 楚辞
- 诗经
- 曹操诗集
- 纳兰性德诗词集
- 等等

### 数据格式

每个分块是一个 JSON 数组，每首诗使用短键名以节省体积：

```json
{
  "t": "静夜思",
  "a": "李白",
  "d": "唐",
  "y": "五言绝句",
  "c": "床前明月光，疑是地上霜。举头望明月，低头思故乡。"
}
```

| 键 | 含义 | 键 | 含义 |
|---|---|---|---|
| `t` | 标题 | `d` | 朝代 |
| `a` | 作者 | `y` | 体裁 |
| `c` | 正文 | | |

### 索引文件

```
data/
├── index.json           # 精简索引（file/count/dynasties，18KB，首屏必需）
├── index-full.json      # 筛选索引（额外含 authors/types，324KB，懒加载）
├── search-index.json    # 搜索摘要索引（标题字符集，标题模糊检索收窄用）
├── 001.json             # 345 个分块，每块 1000 首
├── 002.json
└── ...345.json
```

### 关于缺字「□」

查询界面会显示一条提示：

> 个别文字显示为「□」是原始古籍数据缺损所致，属正常现象，并非程序错误。

这是因为部分古籍原始数据存在缺字或特殊字符，已统一替换为 `□`，不影响阅读体验。

## 📱 功能使用详解

### 随机抽诗

点击「与诗相逢」按钮，系统会从 34 万首诗中加权随机选一首。加权逻辑是按分块内的诗数分配概率，每个分块被选中的概率与其包含的诗数成正比。

### 今日之诗

系统用当前日期生成一个确定性种子（年×10000+月×100+日），再乘以黄金分割常数散列，在索引中跳跃取块、块内跳跃取诗。这样保证所有人当天看到的是同一首诗，而且每天都不一样。

### 搜索

- **智能识别**：自动判断你输入的是作者名、朝代名还是标题片段
- **按作者**：精确匹配作者名（如「李白」）
- **按朝代**：精确匹配朝代名（如「唐」）
- **按标题**：模糊匹配（包含即可，如「月」能搜到所有标题含「月」的诗）
- **体裁组合**：可以在任意搜索模式下叠加体裁筛选

标题模糊检索经过优化：先用搜索摘要索引（`search-index.json`）收窄候选分块，只加载可能命中的分块，避免全量扫描 90MB 数据。

### 收藏与批注

- 收藏和批注都存储在本机（小程序用 `wx.getStorageSync`，网页用 `localStorage` + cookie）
- 不会上传到任何服务器，换设备后不会同步（这是设计如此，保护隐私）
- 收藏支持一键导出为文本

### 分享卡片

用 Canvas 2D 逐字手绘生成，支持横版/竖版双布局。生成时可以选择比例（1:1 正方形 / 3:4 竖长 / 9:16 手机屏 / 自动）。卡片上会显示诗词全文、作者、朝代、logo 水印和你的自定义签名。

### 访问统计

- **小程序**：基于微信云开发数据库的原子递增计数器，每次打开小程序都计数（10 秒短节流防刷量）
- **网页端**：用 `localStorage` 记录本机累计访问天数

## ❓ 常见问题

<details>
<summary><b>打开网页是白屏怎么办？</b></summary>

可能是网络问题，数据分块加载失败。系统会自动重试 3 次。如果还是不行，检查一下网络连接，或者尝试刷新页面。

</details>

<details>
<summary><b>小程序报错「云环境未授权」怎么办？</b></summary>

这说明你的小程序 AppID 还没有在云开发环境中获得授权。去微信开发者工具的「云开发」控制台 → 设置 → 环境 → 环境访问权限，把你的 AppID 添加进去就好了。

</details>

<details>
<summary><b>有些字显示为「□」是 bug 吗？</b></summary>

不是 bug。这是因为原始古籍数据本身就有缺字或特殊字符，已经统一替换为「□」。这属于正常现象，不影响阅读其他内容。

</details>

<details>
<summary><b>收藏和批注换手机后还在吗？</b></summary>

收藏和批注存储在本机本地缓存中，不上传服务器，所以换设备后不会同步。如果需要保留，请在换设备前用「一键导出」功能备份。

</details>

<details>
<summary><b>GitHub Pages 构建失败了怎么办？</b></summary>

GitHub Pages 构建有时会因为 GitHub 端临时限速（429 Too Many Requests）失败，这不是代码问题。等几分钟重新触发构建即可，或者做一个空推送：

```bash
git commit --allow-empty -m "trigger rebuild" && git push origin main
```

</details>

<details>
<summary><b>本地运行时终端提示找不到 python3？</b></summary>

Mac 上可能需要用 `python` 代替 `python3`。或者安装 Python 3：

```bash
brew install python3
```

</details>
